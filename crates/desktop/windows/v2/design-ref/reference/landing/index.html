Как это работает

Три шага до собственной приватной инфраструктуры

01

Выберите VPS

Выберите провайдера L1 (relay) и L2 (exit) из нашего агрегатора. L1 — промежуточный узел для обфускации, L2 — выходной узел в нужной юрисдикции.

02

Мы настроим

Предоставьте доступ к серверам, мы развернём защищённую конфигурацию с WireGuard, двухузловой маршрутизацией и обфускацией трафика.

03

Подключайтесь

Используйте клиент Mirage для безопасного подключения через двухузловую сеть. Ваш трафик защищён на каждом участке маршрута.
